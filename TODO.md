# Taller Mecánico La Cochera — Entregables

## 1. Base visual responsive de la página de inicio
- [x] La página de inicio debe ser responsive y mobile-first, con una identidad premium e industrial.
- [x] Debe usar textos en español y priorizar claridad, confianza y conversión a reserva.
- [x] Debe aplicar una paleta consistente de azul petróleo, naranja seguridad, crema y grafito.
- [x] Debe incluir titulares contundentes, cuerpo sans serif legible, componentes reutilizables y estados hover.

## 2. Navegación y conversión
- [x] El encabezado debe incluir identidad del taller, navegación clara y acceso destacado para agendar una cita.
- [x] El hero debe comunicar la propuesta de valor, generar confianza e incluir una llamada principal a reservar una cita.

## 3. Contenido de confianza y servicios
- [x] Debe existir una sección de servicios principales con presentación visual clara.
- [x] Debe existir una sección de indicadores de confianza sobre experiencia, calidad y respaldo.
- [x] Debe explicar el proceso de atención en pasos simples desde la reserva hasta la entrega.
- [x] Debe incluir testimonios orientados a reforzar credibilidad y conversión.

## 4. Contacto y estructura futura
- [x] Debe incluir ubicación y contacto con datos prácticos y llamadas a la acción.
- [x] Debe incluir un footer completo con navegación secundaria, información del taller y vías de contacto.
- [x] La estructura debe quedar preparada para futuras ampliaciones del sitio.
